# Office Attendance Updates

This repository hosts signed release APKs for the Office Attendance Android app.

## Release format

Each release tag must end with the Android version code, for example v9 or v10, and include the signed APK asset named app-release.apk. Keep the same app ID and signing key for every update.

The app checks this repository for newer releases. Android will ask the device owner to approve installation. Attendance records stay on the phone.
